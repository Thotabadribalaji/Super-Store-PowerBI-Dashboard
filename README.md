An interactive Power BI dashboard developed to analyze Super Store business data and generate meaningful insights through data visualization.

- Microsoft Excel
- Data Cleaning
- Data Transformation
- Data Visualization

- Sales performance
- Profit analysis
- Product category analysis
- Regional performance
- Customer analysis
- Interactive KPIs and filters

## Dashboard

The Power BI dashboard provides interactive visualizations and filters to explore business performance and identify important trends.
